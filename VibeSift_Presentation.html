THE PROBLEM
Slide 3 of 10

Invisible Defects That Silently Break Production Websites

Most pre-launch failures aren't visual layout bugs—they are invisible infrastructure, security, and compliance defects.

SECURITY GAPS
Security & Header Blindspots
  • Missing Strict-Transport-Security (HSTS) enables SSL-strip downgrade attacks.
  • Absence of Content Security Policy (CSP) leaves users vulnerable to XSS.
  • Sensitive dotfiles (e.g. .env, .git) accidentally exposed to the web.
PERFORMANCE DRAG
Core Web Vitals Failures
  • Uncompressed assets and missing cache headers slow First Contentful Paint.
  • Images without explicit dimensions trigger Cumulative Layout Shift (CLS).
  • Heavy unminified bundles degrade mobile user conversion and SEO rankings.
PRIVACY & TRUST
Privacy & Compliance Risks
  • Third-party trackers fire before consent is given, violating DPDP Act (2023).
  • Missing Grievance Officer details and asymmetric "Accept" vs "Reject" buttons.
  • Missing RFC 9116 security.txt prevents responsible vulnerability disclosure.
The Reality: Developers don't ignore these issues on purpose—they lack a simple, automated tool to catch them before launch.

Slide 8 of 10

How the Backend Operates: Request to Report

A step-by-step walkthrough of request validation, security gating, execution, and artifact generation.

PHASE 1
Ingress & SSRF Protection
  • JWT Authentication: API verifies Cognito signature, issuer, expiration, and audience claims.
  • SSRF Defense Matrix: Validates target scheme, ports (80/443), and credentials.
  • DNS Verification: Resolves all DNS IPs; blocks private RFC 1918, loopback, and AWS IMDS (169.254.169.254).
PHASE 2
Parallel Worker Execution
  • State Transition: Monotonic FSM moves scan from QUEUED ➔ VALIDATING ➔ RUNNING.
  • Python Inspector: Executes 34 baseline checks, 22 deep active tests, and 15 DPDP compliance checks.
  • Lighthouse Runner: Headless Chromium measures real Core Web Vitals (LCP, CLS, FCP, TBT).
PHASE 3
Normalization & Storage
  • Deduplication: Merges duplicate findings and masks any sensitive tokens.
  • Score Calculation: Computes Launch Readiness Score (0–100) and 11 category breakdowns.
  • S3 Persistence: Writes report.json and report.md; emits CloudWatch EMF performance metrics.
Fault-Tolerant Design: If an engine encounters a transient timeout, the normalizer produces a PARTIAL report with full error isolation.
